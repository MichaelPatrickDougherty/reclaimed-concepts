# Product card standards

Approved November 3, 2026. Apply across Game Tables, Music, and Building Materials.

## Single product
- One overall 3:2 image frame.
- Product title and description underneath.
- Center descriptions at 70% of image width on desktop (15% space per side), and 80% on mobile at 720px and below (10% per side).
- Write concise copy targeting two desktop lines; allow natural wrapping, typically three to four mobile lines. Do not force identical line counts across devices.

## Paired products
- One overall 3:2 image frame, split into equal 50/50 panels with a narrow padded gap.
- Equal-width copy columns aligned beneath their respective images.
- Apply the same 70% / 80% description widths relative to each product’s half, excluding the gutter.
- Use shorter copy targeting two desktop lines, allowing natural mobile wrapping.
- Approved titles: Wine Key / Wine Stopper; Floating Shelf / Display Shelf.
- Existing composite paired images may remain if their two halves and gutter already match this format.

## Shared rules
- Preserve image proportions and existing visual style.
- Never truncate descriptions, clip overflow, or use ellipses to make copy fit.
- Avoid fixed description heights, reserved blank lines, and forced line breaks.
- Size titles independently from description widths.
- Keep page introduction copy within two lines.
- Review paired title alignment, spacing, image framing, and all three material tabs before publishing.
